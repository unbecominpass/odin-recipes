# Odin Recipes

A mini recipe website to demonstrate my HTML learning journey. The goal of this repo is to practice clean HTML structure—starting with a solid boilerplate—and then improve it as I add more recipes I enjoy, especially Vietnamese dishes.

---

## What I’m practicing

- **Good HTML boilerplate**
- **Basic HTML elements + semantic HTML**
  - clear heading hierarchy (h1 → h2 → h3)
  - meaningful sectioning for recipe pages (description, ingredients, steps, etc.)
- **Relative vs absolute links**
  - navigation using **relative links** between pages
  - understanding when **absolute links** make sense
- **Accessibility (a11y)**
  - descriptive `alt` text on images
  - keyboard-friendly, readable structure
  - semantic layout so screen readers can interpret the page properly
- **Scalable project structure**
  - consistent page layout for each recipe
  - easy-to-follow folder organization

---

## Project structure 

- `index.html` (home page)
